📶 Nearby chat - no internet needed

Chat and share photos and files with someone near you without internet or mobile data. One phone turns on its hotspot (or both use the same Wi-Fi), you scan each other's code once, and messages go straight phone to phone - private and encrypted. Range about 10-30 m indoors on a hotspot, a whole building on Wi-Fi.

  1. Open the menu -> Nearby chat (open it once while online so it also works offline).
  2. One person turns on the phone hotspot, the other joins it.
  3. One taps Start a chat, the other taps Join a chat and scans the code, then the first scans the code on the other phone.
Try it →
